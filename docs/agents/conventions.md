# Conventions

## Service (`src/`, root package)

- 4-space indentation, single quotes, no semicolons. Keep the existing brace spacing style (`{path: req.path}`).
- Every `src/*.ts` file starts with the copyright header block present in all current files.
- ESM with `"type": "module"` and `module`/`moduleResolution` `NodeNext`. Relative imports must keep the `.js` suffix even in TypeScript (`./concurrency.js`).
- `strict: true`, `target: ES2023`. No lint config and no test runner.
- Exported functions and error classes carry JSDoc with `@param`/`@returns`/`@throws`; internal helpers are documented too. Match this when adding code.
- Runtime configuration is read once at module top level in `index.ts` as `Number(env.NAME ?? default)`. Do not re-read `process.env` inside handlers.
- Missing/invalid configuration is not validated beyond `Number()` coercion; `Semaphore` is the only component that hardens its input (floors and clamps to `>= 1`).
- Failures inside the conversion layer are `ConversionError(message, code, stderr?)`. Codes are consumed by the error handler; do not invent HTTP semantics in `convert.ts`.
- Never interpolate a client-supplied filename into a path or header without `sanitizeBaseName` / `stripExtension`.
- Request-path logging uses `Logger` (`debug`/`info` → stdout, `warn`/`error` → stderr) with structured fields. Direct `console.*` calls exist only inside `Logger` and in the startup banner.
- The banner uses `cli-color` only when `stdout.isTTY`, `NO_COLOR` is unset, and `TERM !== 'dumb'`; keep piped/Docker logs plain.
- Version comes from `package.json` via `createRequire(import.meta.url)('../package.json')` and falls back to `unknown`. It resolves in both `src/` (dev) and `dist/` (build).
- `tsconfig` has `removeComments: true`, so JSDoc never ships in `dist/`.

## SDK (`sdk/`)

- Same textual style as the service: 4 spaces, single quotes, no semicolons, copyright header on every file.
- Public types, interfaces, unions and aliases live only in `src/types.d.ts`. Runtime classes live in `.ts`; do not duplicate them as declarations.
- `strict: true`, `target: ES2022`, no lint. Tests use `node:test` and `node:assert/strict` in `.mjs`; they import from `dist/`, not `src/`.
- Core files may only use web-standard APIs. Node built-ins are confined to `src/node.ts`.
- Exported classes and helpers carry JSDoc with `@param`/`@returns`/`@throws`; declarations keep comments because the SDK tsconfigs set `removeComments: false` (deliberate exception to the service setting).
- Keep `.js` suffixes on relative imports in `src/`.
- Public methods (`health`, `convert`) are arrow functions assigned in the class body, so they are own enumerable properties and survive destructuring. Private helpers stay on the prototype; do not move the public methods back.
- README examples are runnable and English; error-code and status tables must match `src/client.ts` and `docs/agents/api.md`.
- The root `README.md` links to `sdk/README.md` for the client: it shows a short quick start only and never duplicates the option or error tables.

## Website (`website/`)

- Tabs for indentation, semicolons, single quotes. Do not reformat with the service's style.
- TypeScript is `noEmit`; type checking happens as part of `npm run build`.
- Components are PascalCase; page sections live in `src/sections/`, reusable primitives in `src/components/`, hooks in `src/hooks/`.
- Styling is plain CSS. `src/styles/tokens.css` holds custom properties; `src/styles/global.css` holds layout and component styles. No UI library.
- Marketing typography is Space Grotesk, technical layer is IBM Plex Mono (loaded through `@fontsource` in `main.tsx`).
- `src/generated/snippets.json` is generated by `scripts/highlight.mjs` from `scripts/snippets.mjs`. Edit the source, then rebuild; do not hand-edit generated HTML.
- Never hard-code software versions. `__SITE_VERSION__` / `__SOFTWARE_VERSION__` and the JSON-LD `softwareVersion` are injected from the two `package.json` files at build time.
- `index.html` owns SEO/OG/JSON-LD tags; keep them factual and consistent with the real API.
- Prerendering depends on the literal `<div id="root"></div>` placeholder in the built HTML. Changing it breaks `scripts/prerender.mjs`.
- Site copy is English; the original Italian design brief (`website/docmorph-landing-brief.md`) is reference material, not a document to ship edits into.
